| 2026-09-19 | [[../slices/S-01-walking-skeleton\|S-01]] | Start the whole system with one command and see it answer: `GET /health`, `GET /health/ready` reporting the database and broker separately, and the API contract as Swagger UI and Redoc over one OpenAPI document, all without a token. | 2026-09-21 | [[../slices/S-02-programs-from-the-treasury\|S-02]] | The treasury creates and changes programs over Kafka (`treasury.capacity`, capacity updates keyed by `programId`), and an authenticated client reads a program's availability: `GET /programs/:programId/availability` answers limit, reserved, available, currency, `overcommitted` and `asOf` in integer minor units. Every business route needs a bearer JWT (HS256, `JWT_SECRET`); health and the documentation do not. A repeated message is counted as a duplicate, an older `eventTime` is recorded stale, a malformed or refused message is dead-lettered to `treasury.capacity.dlq` with the reason in its headers while consumption continues. `npm run dev:token` mints a token, `npm run dev:treasury` publishes an update, and `docker compose up --wait` ends with the sample program `PRG-1` at 10 000 000.00 USD. Every log line is JSON with a correlation id per request and per message. | AC-20, AC-23, AC-24, AC-25, AC-32, AC-33, AC-35, AC-36, AC-37, AC-40, INV-10 | ADR-0005, ADR-0006, ADR-0007 (all accepted before the slice); A-06 and A-13 amended, glossary extended | No reservations yet (S-03), so `reserved` is always 0 and a program is never overcommitted in practice. The snapshot message type is rejected as unknown until S-06. Only HS256 with one shared secret (ADR-0005); the development secret is the compose default and is refused in production. Four minors from the fourth review, deliberately carried into the next slice: the dead-letter publish runs inside the message store transaction (a slow broker can time it out after the publish and produce a second dead letter on redelivery, never a lost one); the AC-40 test's "two ids differ" line compares two constants; an oversized amount in the availability mapper is labelled by currency rather than field; and a stale update with another currency is recorded `stale`, now written down in A-13 (5) but not pinned by a test. |
